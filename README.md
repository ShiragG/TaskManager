# TaskManager

Приложение для ведения заявок: метаданные в SQLite, папка на диске опциональна; заявки группируются по **проектам** (вкладки).

Словарь терминов: [`CONTEXT.md`](CONTEXT.md). Архитектура: [`docs/adr/`](docs/adr/).

## Требования

- [uv](https://astral.sh/uv/)
- Python ≥ 3.13

## Установка

```bash
uv sync --all-groups
```

## Запуск

Без аргументов открывается графическое окно:

```bash
uv run taskmanager
```

Любой аргумент включает режим командной строки: команда выполняется, результат печатается в консоль и процесс завершается. `--help` печатает справку по подкомандам, `--help-all` — справку по всем подкомандам сразу, `--json` переводит вывод в JSON.

```bash
uv run taskmanager --help
uv run taskmanager project list
uv run taskmanager task list --project Alpha
uv run taskmanager task search QUERY
uv run taskmanager --json task list --project Alpha
```

Командной строкой поддерживаются: проекты (создание, переименование, удаление), заявки (список, поиск, создание, изменение, архив, восстановление, скрытие, удаление), папки, комментарии, ссылки, импорт и обновление из источника, экспорт в Excel.

Папка заявки необязательна: без неё `get` отдаёт `"folder": null`, путь создаёт `task folder ensure`. Удаление и архив выполняются сразу, без подтверждения. Если GUI уже открыт, CLI пишет в ту же SQLite; таблицу в окне обновляет F5.

## Рабочий цикл

1. В настройках укажите **рабочую директорию** (`work_dir`).
2. Создайте **проект** (вкладка) — папка на диске появится лениво при первой заявке с папкой или «Открыть папку».
3. При необходимости положите шаблон в `{проект}/{template_name}` (по умолчанию `.template`).
4. Создайте **заявку** — запись в БД; при включённой папке имя каталога = **номер**; при флаге «из шаблона» содержимое копируется из шаблона.
5. **Комментарий** — HTML-поле в БД (отдельно от Notes.txt).
6. Ссылки на заявку хранятся в БД; ПКМ по строке → «Открыть ссылку».
7. **Архив** ставит статус `archived` и переносит папку в `{work_dir}/{archive_name}/{YYYY_MM}/{project}/` если папка есть; режим «Архив» + «Вернуть» для просмотра и восстановления.

## Настройки (`settings.json`)

`settings.json`, `taskmanager.db` и `taskmanager.log` создаются рядом с исполняемым файлом (в режиме разработки — в текущем каталоге запуска).

| Ключ | Назначение |
|------|------------|
| `work_dir` | Корень рабочих папок |
| `template_name` | Имя папки-шаблона в проекте |
| `archive_name` | Имя корня архива |
| `theme_mode` | `light` / `dark` / `system` |
| `highlight_warnings` | Подсветка сроков |
| `warning_lead_days` | За сколько дней до срока (по умолчанию 1) |
| `warning_color` | Цвет подсветки |
| `colors` | Палитра цветов строк |
| `create_task_folder` | Создавать папку заявки по умолчанию |
| `create_notes_file` | Создавать `Notes.txt` и ссылку «Заметки» при новой заявке с папкой |
| `show_priority_colors` | Цвет фона ячейки приоритета по шкале 0→красный … 10→зелёный |
| `keep_priority_on_source_refresh` | Не изменять приоритет при обновлении из источника |
| `debug_logging` | Писать INFO/DEBUG в `taskmanager.log` |

Версия приложения и контакты — в настройках («О приложении»).

## Поиск и навигация

- Ctrl+F / поле поиска — фильтр по номеру, описанию и комментарию на текущей вкладке.
- Чекбоксы **Скрытые** и **Архив** взаимоисключающие.
- Двойной клик — редактирование.
- ПКМ по строке — изменить, открыть папку, архив/вернуть, удалить, обновить/скачать из источника, ссылки.
- ПКМ по вкладке проекта — изменить, открыть папку, удалить.
- **Excel…** — экспорт выбранных проектов (`openpyxl`).
- F5 — обновить текущую вкладку.

## Сборка (PyInstaller)

Сборку выполняйте на целевой ОС (кросс-сборка не поддерживается).

```bash
uv sync --all-groups
uv run pyinstaller --noconfirm --distpath=build/onedir-collect TaskManager.spec
uv run python scripts/package_github_asset.py
```

Готовый asset — `dist/TaskManager` (Linux) / `dist/TaskManager.exe` (Windows). Установщик распаковывает `data/` рядом с exe при первом запуске, затем подменяет себя загрузчиком onedir; `settings.json`, `taskmanager.db` и `modules/` не трогает.
