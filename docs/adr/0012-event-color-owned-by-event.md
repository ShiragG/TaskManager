# Event color is owned by the Event

An Event may have its own optional **Event color**, chosen from the same palette as Task Color. The color is not inherited from a linked Task: a call and that Task’s row would otherwise look like the same object. Priority stays a separate Task field.

**Status:** accepted

## Alternatives rejected

- Inheriting Task Color onto calendar rows — a meeting and the Task line would share a color and be easy to confuse.
- A second palette just for Events — extra settings for the same swatches.
- Reusing Priority as the calendar stripe — Priority is urgency on the Task, not a calendar marker.
