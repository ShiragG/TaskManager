# Windows: единый консольный бинарь с скрытием окна консоли

CLI — полноценный интерфейс продукта: `TaskManager.exe` из терминала должен работать «как из Linux» — печать таблиц и `--json`, перенаправление (`>`), pipe (`|`), корректные коды возврата (`%errorlevel%` / `$LASTEXITCODE`), синхронный захват терминала. Оконная сборка (`console=False`) этого физически не даёт: процесс без консольных хэндлов не наследует каналы, cmd/PowerShell запускают его асинхронно, а `AttachConsole` пишет только на экран консоли (`CONOUT$`), не в pipe. Поэтому сборка переключена на консольную подсистему (`console=True`).

Двойной клик по exe (или запуск из Explorer) должен открывать GUI без окна консоли. ОС сама создаёт новую консоль для консольного приложения; она принадлежит только нашему процессу (`GetConsoleProcessList() == 1`), поэтому GUI-ветка прячет её (`ShowWindow(GetConsoleWindow(), SW_HIDE)`) до создания окна. Если консоль общая с терминалом (cmd/PowerShell), скрывать нельзя — окно принадлежит пользователю, `GetConsoleProcessList()` вернёт больше одного процесса.

**Контракт консоли.** CLI-ветка консоль не трогает: stdout/stderr настоящие, pipe и перенаправление работают, коды возврата доходят до оболочки. Запуск GUI **из** открытого терминала без аргументов ведёт себя как под Linux: консоль остаётся видимой, промпт заблокирован до закрытия окна. `AttachConsole`/`console.py`-хелпер удалён.

**Status:** accepted

## Considered Options

- **Оконная сборка + `AttachConsole` (предыдущее решение)** — не даёт pipe/redirect и синхронности, вывод молча пропадает при запуске из GUI-процесса; противоречит контракту «как из Linux». Отклонено.
- **Два бинаря: `TaskManager.exe` (GUI) + `TaskManager-cli.exe` (консоль)** — максимально чисто, но удваивает артефакты дистрибутива и точки входа; единый бинарь выбран из-за простоты выпуска и одного источника логики.
- **`console=True` + скрытие эксклюзивной консоли (выбрано)** — единственный способ дать полный CLI-контракт одним exe. Цена: кратковременная вспышка окна консоли при двойном клике (поведение платформы) и то, что падения GUI печатаются в скрытую консоль.

## Consequences

- `console=False` заменён на `console=True` в `TaskManager.spec`; Windows-команда сборки в `README.md` использует PyInstaller без `--windowed`.
- `src/taskmanager/cli/console.py` теперь содержит `hide_console_if_only_ours()` (win32 only); вызывается только из GUI-ветки `run_gui()` до создания окна.
- Запуск GUI из терминала блокирует промпт (Linux-парадигма); Ctrl+C закрывает GUI.
- Обновлён реестр ADR 0014 (`console=False` → 0015).
